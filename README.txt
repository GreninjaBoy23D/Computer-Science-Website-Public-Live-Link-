HOW TO CUSTOMIZE
1. Open the folder in a code editor (such as VS Code).
2. Replace the sample biography text in about.html with your own details.
3. Replace the starter/sample work cards in works.html with real projects, screenshots, and project links.
4. Update the social URLs and email address in connect.html.
5. Replace "YOUR NAME" in the footer on each page.
6. To add a profile photo, replace the portrait placeholder in about.html with an img element and your image file.
7. Open index.html in a browser to preview. For local development, use VS Code Live Server or another static web server.

This is a static website: no build tools, server, or dependencies are required. Google Fonts are loaded online; fallback fonts are included.
